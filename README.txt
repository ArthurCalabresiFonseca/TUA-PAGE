# TUA Contabilidade

Site responsivo feito com HTML, CSS e JavaScript.

## Estrutura

- `index.html` — estrutura do site
- `style.css` — visual e responsividade
- `script.js` — animações e carrossel
- `img/logoTUA.png` — logo
- `img/imagem1TUA.png` — mulher com roupa preta
- `img/imagem2TUA.jpeg` — mulher com roupa branca

## Como colocar as imagens

Coloque os três arquivos exatamente dentro da pasta `img`:

- imagem1TUA.png
- imagem2TUA.jpeg
- logoTUA.png

## Como editar os clientes

No `index.html`, procure por:

`<article class="testimonial">`

Cada bloco representa um cliente. Basta mudar o `<h3>` e o `<p>`.

Para adicionar outro cliente, copie um bloco inteiro `.testimonial` e cole abaixo dos outros.

O JavaScript cria automaticamente as bolinhas e ajusta o carrossel.

## Como colocar os links

No final do `index.html`, procure pelos dois:

`<a class="contact-button" href="#">`

Troque o `#` pelo link que quiser.

## Abrir o site

Abra o `index.html` no navegador.

Para publicar, envie os arquivos para o serviço de hospedagem que você escolher.
